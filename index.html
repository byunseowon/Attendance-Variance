출석률 비교 프로그램
백오피스와 HRD-Net 출석 데이터를 자동으로 비교합니다.
Step 1
Redash 연결
Redash에서 현재 운영 중인 트랙과 기수 목록을 자동으로 불러옵니다. 사용자는 별도 설정 없이 드롭다운에서 선택합니다.
Step 2
HRD 출석부 업로드
HRD-Net에서 내보낸 출석부 엑셀(.xlsx / .xls)을 업로드합니다. 첫 번째 시트의 데이터를 자동으로 읽고, Redash 조회 결과와 자동 비교합니다.
Step 3
트랙·기수 선택
트랙을 먼저 선택하면 해당 트랙의 과거 및 현재 기수만 표시됩니다. 기수를 선택하면 Redash 출결 데이터가 자동으로 조회됩니다. HRD 엑셀을 올리면 비교 결과가 자동으로 표시됩니다.
